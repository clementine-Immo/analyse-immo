# Analyse Immo

Saisissez une ville française : l'application réunit sa démographie, ses prix au m², les typologies
de biens les plus et les moins recherchées et l'actualité locale, à partir des seules données publiques
(Insee, DVF de la DGFiP, Google Actualités, annuaire de l'Éducation nationale).

Le premier affichage d'une commune prend une à trois minutes, le temps de télécharger les fichiers
de ventes ; les consultations suivantes sont immédiates.
